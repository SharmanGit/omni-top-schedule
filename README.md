# Omni TOP Mobile (Android)

Современное нативное Android-приложение для преподавателей Академии TOP (Omni TOP). Приложение объединяет расписание занятий по всем филиалам преподавателя, отслеживает проведение и отметку пар, предоставляет интерактивный виджет на рабочий стол и работает полностью автономно с поддержкой офлайн-режима.

---

## Ключевые возможности

1. **Мульти-филиальное расписание**:
   - Автоматическое обнаружение всех привязанных филиалов (Академия, Колледж, Школа, др. города).
   - Агрегация пар в единую временную ленту с удобной навигацией по неделям и дням.
   - Фильтрация по филиалам и суммарный счётчик занятий.

2. **Статусы пар и посещаемость**:
   - Индикация отмеченных пар (проставлена посещаемость/оценки).
   - Поддержка нестандартных мастер-классов и мероприятий без привязки к группам.
   - Детальный просмотр информации о занятии (номер аудитории, дисциплина, группа, время).

3. **Интерактивный виджет Glance**:
   - Настраиваемый виджет таймлайна (4×2) на домашний экран Android.
   - Актуальное расписание на день прямо на рабочем столе с быстрым открытием карточки занятия по тапу.
   - Энергоэффективное периодическое обновление без жора батареи.

4. **Фоновая синхронизация (WorkManager)**:
   - Автоматическая тихая синхронизация расписания в фоне.
   - Ограничения по низкому заряду батареи (`setRequiresBatteryNotLow`) и тихий ночной режим (23:00–07:00).

5. **Офлайн-режим и локальная база Room**:
   - Мгновенная загрузка из локальной базы данных Room (SQLite).
   - Безопасное локальное хранение сессии с поддержкой быстрого переключения/смены пользователей (clean-slate logout).

6. **Оптимизация и безопасность**:
   - Полная R8/Proguard обфускация и минификация ресурсов (`minifyEnabled true`, `shrinkResources true`).
   - Итоговый размер релизного APK всего ~3 МБ.

## Сборка и запуск

### Требования
- JDK 17
- Android SDK 36 (minSdk 26)

### Локальная сборка релизного APK
```bash
cd android
./gradlew assembleRelease
```
Готовый APK файл появится по пути:
`android/app/build/outputs/apk/release/app-release.apk`

### Сборка через GitHub Actions
В репозитории настроен workflow `.github/workflows/build.yml`:
- Запускается вручную через вкладку **Actions** -> **Build Android Release** -> **Run workflow** (`workflow_dispatch`).
- Также автоматически запускается при пуше в ветки `main` / `master`.
- Скомпилированный `app-release.apk` прикрепляется к запуску пайплайна в виде артефакта (`OmniTOP-release-apk`).
