# Omni TOP Mobile (Android)

Нативное Android-приложение для преподавателей Академии TOP (**Omni TOP**). Объединяет расписание по всем филиалам с учётом их часовых поясов, отслеживает проведение и отметку посещаемости пар, синхронизирует занятия в Google Календарь / Календарь устройства, показывает очередь ДЗ и отзывов и работает офлайн.

📥 **[Скачать актуальную версию (APK) из GitHub Releases](https://github.com/SharmanGit/omni-top-schedule/releases/latest)**

---

## Ключевые возможности

1. **Мульти-филиальное расписание и часовые пояса**:
   - Автоматическое обнаружение всех привязанных филиалов (Академия, Колледж, Школа, Онлайн, разные города).
   - Автоматический расчёт времени пар по часовому поясу каждого филиала (`BranchTimeZoneResolver`) для корректных статусов *«Идёт сейчас»* и *«Следующая»*.
   - Фильтрация по филиалам и навигация по неделям и дням.

2. **Синхронизация с Календарём (Google Календарь / Календарь устройства)**:
   - Включается в разделе **Профиль → Синхронизация с Календарём**.
   - Выбор конкретного календаря на устройстве (например, нужного Google-аккаунта).
   - Автоматическое обновление и удаление отменённых пар, а также полная очистка добавленных событий при отключении или выходе из аккаунта.

3. **Задачи: ДЗ и отзывы о студентах**:
   - Счётчики непроверенных ДЗ и отзывов в шапке приложения.
   - Список студентов на отзыв с группой, предметом, сроком (дедлайном) и быстрым переходом в Omni TOP.

4. **Статусы пар и посещаемость**:
   - Индикация текущей, следующей и прошедших пар, а также статуса отметки посещаемости.
   - Поддержка мастер-классов и мероприятий без привязки к учебным группам.

5. **Интерактивный виджет Glance и фоновая синхронизация**:
   - Виджет расписания (4×2) на домашний экран Android с учётом часовых поясов филиалов.
   - Фоновое обновление через `WorkManager` с бережным расходом батареи.

6. **Обновления и безопасность**:
   - Проверка и скачивание новых версий прямо из приложения (**Профиль → О приложении → Проверить обновления**).
   - Шифрованное хранение сессии и учётных данных (`EncryptedSharedPreferences` / Android Keystore), R8-обфускация и подписанные релизные APK.

## Сборка

### Требования
- JDK 17
- Android SDK 36 (`minSdk 26`)

### Локальная сборка APK
```bash
cd android
./gradlew testReleaseUnitTest assembleRelease
```
Готовый APK появится в `android/app/build/outputs/apk/release/app-release.apk`.

### Сборка через GitHub Actions
Workflow [`.github/workflows/build.yml`](.github/workflows/build.yml):
- Автоматически запускает unit-тесты и собирает APK при пуше в `main` или теге `v*`.
- При запуске с тегом `v*` (или через **Run workflow** с флагом `create_release: true`) подписывает APK секретами репозитория и публикует GitHub Release.
